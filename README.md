Что реализовано
- REST API и база данных: CRUD для студентов, преподавателей, курсов и записей на курсы; EF Core, миграции, DTO, AutoMapper, Repository Pattern и единый формат ответов.
- Безопасность: ASP.NET Core Identity, регистрация и вход, JWT, хеширование паролей, блокировка после неудачных попыток входа.
- Авторизация: роли Admin, Teacher, Student; студент видит свои записи и оценки, преподаватель меняет оценки только на собственных курсах. Для отказа в доступе используются HTTP 401 и 403.
- CORS: именованная политика UniversityClients с двумя разрешёнными адресами.
- MVC-клиент: отдельное приложение с просмотром списка и деталей курсов, IHttpClientFactory и обработкой ошибок API.
- Версии API: v1 с базовой информацией о курсах; v2 дополнительно возвращает teacherName и studentCount. Сохранён исходный /api/courses, настроены два Swagger-документа.
- Тесты: проект xUnit с 20 проверками API, JWT, ролей, доступа к оценкам и совместимости версий.
