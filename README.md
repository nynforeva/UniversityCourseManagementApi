# University Course Management API

В рамках практической работы я разработала REST API для системы управления университетскими курсами на ASP.NET Core и C#.

Приложение предназначено для работы со студентами, преподавателями, учебными курсами и записями студентов на курсы.

## Реализация проекта

Я создала четыре основные сущности: `Student`, `Teacher`, `Course` и `Enrollment`, настроила связи между ними и подключила PostgreSQL через Entity Framework Core с использованием миграций.

Для каждой сущности реализовала CRUD-операции с HTTP-методами GET, POST, PUT и DELETE. Также добавила получение курсов студента, фильтрацию курсов, изменение оценок и проверку повторной записи на курс.

В проекте использовала Repository Pattern, Service Layer и Dependency Injection для разделения логики приложения. Для передачи данных создала DTO и настроила AutoMapper.

Дополнительно реализовала единый формат ответов `ReturnResult<T>`, валидацию данных, централизованную обработку ошибок и логирование через `ILogger`. API возвращает соответствующие HTTP-статусы: `200`, `201`, `400`, `404`, `409` и `500`.

## Архитектура

Приложение построено по многослойной архитектуре:

`Client → Controller → Service → Repository → Entity Framework Core → PostgreSQL`
