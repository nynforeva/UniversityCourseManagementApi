В рамках практической работы я разработала REST API для системы управления университетскими курсами с использованием ASP.NET Core и C#.

Приложение предназначено для управления студентами, преподавателями, учебными курсами и записями студентов на курсы.

## Что было реализовано

В ходе работы я:

1 Создала четыре сущности: `Student`, `Teacher`, `Course`, `Enrollment`.
2 Реализовала CRUD-операции с использованием HTTP-методов GET, POST, PUT и DELETE.
3 Подключила базу данных PostgreSQL через Entity Framework Core.
4 Настроила связи между таблицами и миграции базы данных.
5 Реализовала Repository Pattern и Service Layer для разделения логики приложения.
6 Использовала Dependency Injection для управления зависимостями.
6 Создала DTO и настроила AutoMapper.
7 Реализовала единый формат ответов API через `ReturnResult<T>`.
8 Добавила валидацию данных и централизованную обработку ошибок.
9 Настроила логирование с помощью `ILogger`.
10 Подключила Swagger для тестирования API.

## Функциональность API

Разработанное приложение позволяет:

- Создавать, просматривать, изменять и удалять студентов и преподавателей.
- Создавать учебные курсы и назначать преподавателей.
- Записывать студентов на курсы.
- Просматривать курсы, на которые записан студент.
- Изменять оценки студентов.
- Фильтровать курсы по названию и преподавателю.
- Предотвращать повторную запись студента на один курс.
- Обрабатывать ошибки и возвращать соответствующие HTTP-статусы: `200`, `201`, `400`, `404`, `409`, `500`.

## Архитектура проекта

В приложении использована многослойная архитектура:

```text
Client → Controller → Service → Repository → Entity Framework Core → PostgreSQL
```

Такое разделение позволяет отделить обработку HTTP-запросов, бизнес-логику и работу с базой данных.
