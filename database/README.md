База данных PostgreSQL
В ходе практической работы я создала базу данных UniversityCourseManagementDb для хранения информации о студентах, преподавателях, учебных курсах и записях студентов на курсы.

Для взаимодействия с базой данных я использовала Entity Framework Core и PostgreSQL.

В папке находится файл UniversityCourseManagementDb.backup — резервная копия базы данных, созданная с помощью pgAdmin.

База данных используется для выполнения CRUD-операций через разработанный REST API.
